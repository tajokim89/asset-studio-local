# 스프라이트 조작 예시

에셋을 포함하지 않는 코드 예시입니다. `sprites.example.json`을 `sprites.json`으로 복사한 뒤 새 게임의 시트 경로, 프레임 수, FPS, 열 수, 셀 크기와 발 피벗을 지정하세요. 예시 숫자는 이전 실험의 값이며 다른 이미지에 그대로 맞지 않습니다.

이 폴더에서 `python -m http.server 8000`을 실행하고 브라우저에서 열 수 있습니다. 필요한 에셋이 없으면 로딩 실패 메시지가 나옵니다. WASD/방향키 이동, Shift 달리기, Space 공격을 지원합니다. 도끼 예시는 걷기와 공격만 연결되어 있습니다. 이동 속도와 애니메이션 FPS는 별도입니다.
