# 3D → 도트 이미지 변환 조사 자료

3D 렌더링 및 AI 보조 제작물을 레트로/픽셀아트 게임 이미지로 전환하는 사례를 조사하면서 확보한 문서 모음입니다.

## 구성

- `youtube_analysis/`: 3D·2D 게임 에셋 생성 및 렌더링 파이프라인 관련 영상 메타데이터, 전체 자막, 정리 자료
- `youtube_analysis_3/`: AI 보조 픽셀아트 사례 3편의 메타데이터, 전체 자막, 한국어 종합 분석
- `MOVE_MANIFEST.json`: 원래 위치, 이동 위치, 크기, 수정 시각, SHA-256을 기록한 이동 검증표

## 먼저 읽을 문서

- `youtube_analysis_3/analysis_ko.md` — 세 사례의 실제 산출물, AI와 수작업의 역할, 일관성 장치, 실패와 게임 적용 수준 비교
- `youtube_analysis/zEfBPmPDUVc.transcript.timed.txt` — 3D·2D 게임 에셋 생성 영상의 타임코드 자막
- `youtube_analysis/zEfBPmPDUVc.metadata.summary.json` — 해당 영상의 핵심 메타데이터

## 이동 범위

문서 형식(`.md`, `.txt`, `.json`, `.json3`, `.vtt`) 34개만 이곳으로 이동했습니다. 원본 조사 폴더의 MP4·JPG 등 영상·이미지는 삭제하지 않고 원래 위치에 보관했습니다.
